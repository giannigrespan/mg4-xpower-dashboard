# MG4 XPower Dashboard

Dashboard standalone per il monitoraggio consumi energetici della MG4 XPower (targa GP521VR).

## Dati
- Fonte Wallbox (CSV sessioni)
- Fonte Drivvo (XLSX km e ricariche esterne)
- Bollette Octopus Go

Tema scuro, Chart.js, HTML autocontenuto.

## Deploy
Collegato a Vercel via GitHub. Ogni push su `main` aggiorna la produzione.
